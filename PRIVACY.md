# Privacy Policy

Effective: 2026-11-24. Contact: luozn123@gmail.com.

This OAuth application ("rclone", project `rclone-backup`) exists solely to let rclone, running on a private server owned by luozn123, upload daily database backup files to the owner's own Google Drive account.

- Data accessed: only files created by rclone itself in Google Drive (`drive.file` scope). The app cannot see, read, or modify any other file in the account.
- Data collected: none. No personal data is collected, stored, transmitted to third parties, or used for any other purpose.
- Credentials: the OAuth tokens are stored only on the owner's own server and are never shared.
- Removal: revoke access at any time from the Google Account permissions page; the app stops working immediately.
